Deskripsi Proyek

Proyek ini merupakan implementasi Sistem Informasi Perpustakaan berbasis REST API menggunakan PHP, MySQL, dan JavaScript.

Fitur yang Dibuat

1. Dashboard untuk menampilkan statistik perpustakaan.
2. Menampilkan data buku.
3. Menambahkan data buku.
4. Mengubah data buku.
5. Menghapus data buku.
6. Menampilkan data kategori.
7. Menambahkan kategori buku.
8. Mengubah kategori buku.
9. Menghapus kategori buku.
10. Integrasi frontend dengan REST API.

Teknologi yang Digunakan

- PHP
- MySQL
- JavaScript
- HTML
- CSS
- Tailwind CSS
- Composer

Cara Menjalankan Proyek

1. Menjalankan Backend

Buka terminal, masuk ke folder backend:

```bash
cd rest-api-perpustakaan
```

Jalankan server:

```bash
php -S localhost:8000 -t public
```

2. Menjalankan Frontend

Buka terminal baru, masuk ke folder frontend:

```bash
cd rest-api-perpustakaan/frontend-perpustakaan
```

Jalankan server:

```bash
php -S localhost:3000
```

### 3. Membuka Aplikasi

Buka browser dan akses:

http://localhost:3000
